# Свои видео

Вертикальная видеолента для Android с привычными свайпами, как в TikTok, но из роликов на твоём телефоне. Без аккаунта, сервера и облачной загрузки.

**React Native · Expo SDK 57 · TypeScript · Android 7+**

## Возможности

- Полноэкранное вертикальное перелистывание и автозапуск выбранного видео.
- Пауза по касанию, перемотка, управление звуком и повтором.
- Автоматический переход к следующему ролику после окончания.
- Сортировка «новые сначала» и перемешивание без повторений за один проход.
- Закладки и отдельная лента отмеченных видео.
- Сохранение настроек, порядка и последнего просмотренного ролика.
- Переход к видео по номеру, обновление библиотеки и отправка через системное меню Android.
- Тёмный интерфейс; горизонтальные ролики показываются целиком.

При сворачивании приложения, блокировке экрана и открытии меню воспроизведение приостанавливается. В памяти находятся данные каталога и плееры текущего ролика и ближайших соседей, а не вся коллекция видео.

## Локальные файлы и приватность

Приложение читает видео, доступные через системную медиатеку Android. Для просмотра не нужен интернет: файлы не загружаются на сервер и не копируются в отдельную библиотеку. Фото и аудио не запрашиваются.

Кнопка «Поделиться» создаёт временную копию только выбранного ролика и открывает системное меню. Приложение и получателя выбирает пользователь; исходный файл остаётся на месте. Копии старше суток очищаются при следующем запуске или отправке. Для отправки нужно свободное место размером с выбранное видео.

Облачные ролики, не сохранённые на телефон, и файлы в закрытых каталогах других приложений не входят в ленту. Поддержка видеокодеков зависит от устройства. При ограниченном разрешении Android приложение видит только выбранные пользователем видео.

## Установка на Android

Готовый подписанный APK: [Releases](https://github.com/xChessman-dev/lk-tt/releases). Для версии 1.1.2 скачайте `svoi-video-1.1.2.apk`; рядом опубликован SHA-256 для проверки целостности.

Откройте APK на телефоне, разрешите установку этому файловому менеджеру, если Android попросит, и после установки выдайте доступ к видео. Для полной ленты разрешите чтение всех видео; при ограниченном доступе будут видны только выбранные ролики. Требуется Android 7 или новее.

Обновление устанавливается поверх версии с тем же ключом подписи. Не удаляйте старую копию заранее: при удалении приложения исчезнут его настройки и закладки.

## Запуск проекта

Нужны Node.js 22.13 или новее и npm. Для разработки и проверок используется Node.js 24.

```bash
git clone git@github.com:xChessman-dev/lk-tt.git
cd lk-tt
npm ci
npm start
```

Основной сценарий — Android. Веб-режим позволяет посмотреть интерфейс, но не заменяет работу с медиатекой телефона.

## Сборка APK на Windows

Нужны PowerShell 7, JDK 17 и Android SDK: платформа 36, Build Tools 36, Platform Tools и NDK версии, которую использует сгенерированный Expo-проект.

```powershell
npm ci
pwsh -NoProfile -File scripts/build-apk.ps1 `
  -JavaHome 'F:/AndroidTools/jdk17' `
  -AndroidSdk 'F:/AndroidTools/sdk'
```

Скрипт выполняет Expo prebuild, собирает release APK, подписывает его локальным ключом и сохраняет результат вместе с SHA-256 в `artifacts/`. Для текущей версии имя файла — `svoi-video-1.1.2.apk`.

При первой сборке создаётся новый ключ в `.credentials/`. Сохрани резервную копию этой папки вне репозитория: для обновлений поверх установленного приложения нужен тот же ключ. APK, собранный другим ключом, не установится как обновление существующей копии.

APK публикуется отдельно в Releases, а не в истории исходников. Личные ключи подписи, Android SDK и локальные видео в репозиторий не входят.

## Проверки

```bash
npm test
npm run typecheck
```

21 тест проверяет каталог из 1753 синтетических записей, порционное чтение, дедупликацию, перемешивание, закладки, восстановление позиции, переход по номеру, свайпы, перемотку и состояния воспроизведения. Тесты компонента ленты используют заглушки нативных элементов и проверяют сохранение экземпляров плееров и обработку событий.

Эти проверки не заменяют тестирование воспроизведения, разрешений и жестов на реальном Android-устройстве. GitHub Actions запускает тесты и проверку типов для коммитов и pull request.

## Структура

```text
src/app/          Экран приложения и маршрутизация
src/components/   Видеолента, плеер и элементы управления
src/hooks/        Чтение медиатеки и сохранение настроек
src/lib/          Каталог, порядок просмотра и логика воспроизведения
tests/            Тесты логики и компонента ленты
plugins/          Настройка локальной release-подписи
scripts/          Сборка APK и подготовка иконки
assets/           Иконки приложения
```
